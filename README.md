# Video Review Studio (MVP)

動画を再生しながら、評価・タグ付け・コメント記録ができるWebアプリケーションです。

## 特徴
- **2カラム構成の評価画面**: 動画を再生しながら評価、タグ、コメント、タイムライン引用メモを入力できます。
- **カスタマイズ可能な星評価**: 設定画面で評価項目（最大6個）を自由に追加・編集・並べ替え可能です。
- **動的SVGレーダーチャート**: 個別評価が変更されるとリアルタイムでポリゴン形状が更新されます。
- **タイムライン引用メモ**: 再生中の特定時刻の切り取り、 canvas を利用した動画サムネイルの自動生成、クリックによる該当フレームへのシーク機能を備えています。
- **完全ローカル永続化**: 評価結果は `localStorage` にリレーショナル形式で保存されるため、リロードしてもデータは復元されます。
- **セキュリティ・サンドボックス対応**: ローカル動画ファイルはセキュリティ制限に配慮し、ファイル名・サイズ等を元にした独自署名で管理されます。

## 起動方法

Node.js/npmがインストールされていない環境のため、Pythonの簡易サーバーを使用して起動します。

1. ターミナルを開きます。
2. 以下のコマンドを実行してローカルサーバーを起動します。
   ```bash
   python3 -m http.server 8000
   ```
3. ブラウザで以下のURLを開きます。
   [http://localhost:8000](http://localhost:8000)

## キーボードショートカット
テキスト入力中でない場合に以下のキーボード操作に対応しています：
- `Space`: 再生 / 一時停止
- `← / →`: 5秒戻る / 進む
- `Shift + ← / →`: 10秒戻る / 進む
- `M`: ミュート（消音）の切り替え
- `T`: 現在の再生時刻を引用してタイムライン入力欄にフォーカス
- `Ctrl + S` または `Cmd + S`: 評価内容の強制手動保存
